Smart Books 📚

Интернет-магазин книг в Бишкеке на чистом HTML, CSS и JavaScript. Без сборки, без зависимостей, без сервера: загрузили папку на хостинг, и сайт работает.

Главная идея: покупатель добавляет книги в корзину, а его герой прокачивается от новичка до легенды. Чем выше уровень, тем выгоднее заказ.

Возможности
Герой-аватар. Рисуется в SVG слоями: 6 образов × 6 уровней (Новичок → Легенда). Образ зависит от жанра книг в корзине.
Каталог. Фильтр по категориям, поиск, карточки с ценой. Надпись «Осталось N» появляется только когда книг мало.
Корзина. Количество с учётом остатков, автоматические скидки, оформление заказа в WhatsApp с готовым текстом сообщения.
Трекер действий (tracker.html). Покупатель добавляет книгу и получает список шагов, как применить её на практике. Есть прогресс и серия дней подряд.
Админ-панель (admin.html). Правка цен, остатков, названий, описаний и категорий, скрытие и удаление книг, добавление новых с фото.
Плавающая кнопка WhatsApp, которая едет вместе с экраном.
SEO. Уникальные title, description и Open Graph на каждой странице, микроразметка JSON-LD (магазин, каталог с ценами, FAQ), семантические заголовки, robots.txt.
Адаптивность. Удобно на телефоне и компьютере, учитывается prefers-reduced-motion.
