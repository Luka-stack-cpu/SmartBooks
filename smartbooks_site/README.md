# Smart Books — сайт

Статический сайт: ничего устанавливать не нужно. Загрузите всю папку на любой хостинг (Netlify, Cloudflare Pages, GitHub Pages, обычный хостинг) — и сайт работает.

## Страницы
- `index.html` — главная: герой, каталог, корзина, уровни и скидки, вопросы
- `tracker.html` — трекер действий после книги
- `admin.html` — админ-панель (не индексируется поисковиками)

## Настройки (в `js/data.js`, блок `config`)
- `whatsapp` — номер без «+» и пробелов (сейчас 996775197277)
- `instagram` — ссылка на аккаунт
- `lowStock` — порог для надписи «Осталось N» (сейчас 5)
- `discounts` — скидки: от 2 книг 10%, от 3 книг 15%
- `freeDeliveryFrom` — бесплатная доставка от N книг (сейчас 10)

## Админ-панель
1. Откройте `admin.html`, при первом входе придумайте PIN (он хранится только в вашем браузере).
2. Меняйте цены, остатки, названия, описания, скрывайте или удаляйте книги, добавляйте новые с фото.
3. «Сохранить» — правки видны вам в этом браузере. «Опубликовать» — скачается `data.js`; замените им файл `js/data.js` на хостинге, и изменения увидят все покупатели.

Важно: PIN в админке защищает только от случайных нажатий, это не настоящая защита. Реальное мгновенное обновление остатков для всех покупателей требует подключения базы данных (Google Таблицы, Firebase или Supabase).

## SEO
- Уникальные title, description, keywords, Open Graph на каждой странице; микроразметка JSON-LD: магазин, каталог товаров с ценами, вопросы и ответы.
- Чтобы заработали canonical, sitemap.xml и абсолютные ссылки в разметке, нужен домен: пришлите адрес сайта, и я пересоберу страницы с нужными ссылками.
- Подключите сайт в Google Search Console и Яндекс Вебмастер, отправьте sitemap.xml.
